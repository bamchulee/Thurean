# 📊 Google Sheets Data Management (Local Mirror)

โฟลเดอร์นี้เก็บข้อมูลของ Google Sheets ทุกแท็บในรูปแบบไฟล์ **CSV (UTF-8)** เพื่อให้คุณและ **Claude** สามารถเปิดดู แก้ไขโครงสร้างคอลัมน์ หรือปรับข้อมูลได้จากในโปรเจกต์โดยตรง เมื่อแก้ไขเสร็จแล้วสามารถสั่งอัปโหลดกลับขึ้น Google Sheet จริงได้ทันทีด้วยคำสั่งเดียว!

> ⚠️ **ไฟล์ `*.csv` ในโฟลเดอร์นี้ไม่ขึ้น git** (อยู่ใน `.gitignore`) เพราะ `sheets:pull` ดึงข้อมูลลูกค้าจริงลงมา
> ไฟล์ที่ commit ได้มีแค่ `README.md` นี้ — **โครงสร้างคอลัมน์จริงอยู่ที่ `SHEET_DEFS` ใน `google-apps-script/1_Config.gs`** (แก้ที่นั่น → `npm run sheets:schema` อัปเดตไฟล์นี้กับ CSV → deploy Apps Script → รัน `setupDurianWinkinSheets` ชีตจริงจะจัดลำดับคอลัมน์ตามให้เอง ข้อมูลไม่หาย)
> ไฟล์ CSV ที่มีแต่หัวคอลัมน์ = แม่แบบ schema — `sheets:push` จะข้ามให้อัตโนมัติ ไม่ล้างข้อมูลจริงบนชีต
> `sheets:push` ไม่ยอมอัปโหลดไฟล์ที่ลำดับคอลัมน์ไม่ตรง `SHEET_DEFS` (กันชีตจริงกลับไปเรียงผิด) และส่ง `Users` ไปไฟล์ USER ส่วนตารางอื่นไปไฟล์ THUREAN

## 🚀 คำสั่งซิงก์ข้อมูล (Commands)

รันคำสั่งเหล่านี้ผ่าน Terminal ในโฟลเดอร์ `durian-shop`:

```bash
# 1. ดึงข้อมูลล่าสุดจาก Google Sheets ลงมาที่ไฟล์ sheets/*.csv
npm run sheets:pull

# 2. แก้ไขข้อมูลใน sheets/*.csv เสร็จแล้ว อัปโหลดกลับขึ้น Google Sheets จริง
npm run sheets:push

# 3. แปลงข้อมูลจาก sheets/*.csv ไปอัปเดตลง data/local-db.json (สำหรับทดสอบในเครื่อง)
npm run sheets:to-local

# 4. แปลงข้อมูลจาก data/local-db.json ออกมาเป็น sheets/*.csv
npm run sheets:from-local
```
