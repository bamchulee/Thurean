# 📊 Google Sheets Data Management (Local Mirror)

โฟลเดอร์นี้เก็บข้อมูลของ Google Sheets ทุกแท็บในรูปแบบไฟล์ **CSV (UTF-8)** เพื่อให้คุณและ **Claude** สามารถเปิดดู แก้ไขโครงสร้างคอลัมน์ หรือปรับข้อมูลได้จากในโปรเจกต์โดยตรง เมื่อแก้ไขเสร็จแล้วสามารถสั่งอัปโหลดกลับขึ้น Google Sheet จริงได้ทันทีด้วยคำสั่งเดียว!

> ⚠️ **ไฟล์ `*.csv` ในโฟลเดอร์นี้ไม่ขึ้น git** (อยู่ใน `.gitignore`) เพราะ `sheets:pull` ดึงข้อมูลลูกค้าจริงลงมา
> ไฟล์ที่ commit ได้มีแค่ `README.md` นี้ — **โครงสร้างคอลัมน์จริงอยู่ที่ `SHEET_DEFS` ใน `google-apps-script/1_Config.gs`** (แก้ที่นั่น แล้ว deploy Apps Script + รัน `setupDurianWinkinSheets` ชีตจะเติมคอลัมน์ที่ขาดให้เอง)
> ไฟล์ CSV ที่มีแต่หัวคอลัมน์ = แม่แบบ schema — `sheets:push` จะข้ามให้อัตโนมัติ ไม่ล้างข้อมูลจริงบนชีต

## 🚀 คำสั่งซิงก์ข้อมูล (Commands)

รันคำสั่งเหล่านี้ผ่าน Terminal ในโฟลเดอร์ `durian-shop`:

```bash
# 1. ดึงข้อมูลล่าสุดจาก Google Sheets ลงมาที่ไฟล์ sheets/*.csv
npm run sheets:pull

# 2. แก้ไขข้อมูลใน sheets/*.csv เสร็จแล้ว อัปโหลดกลับขึ้น Google Sheets จริง
npm run sheets:push

# 3. แปลงข้อมูลจาก sheets/*.csv ไปอัปเดตลง data/local-db.json (สำหรับทดสอบในเครื่อง)
npm run sheets:to-local

# 4. แปลงข้อมูลจาก data/local-db.json ออกมาเป็น sheets/*.csv
npm run sheets:from-local
```

## 📋 แผนโครงสร้างคอลัมน์ใหม่ (Schema Definition)

### 🍈 1. แท็บ Products (สินค้า)
* **คอลัมน์ที่เก็บใน Sheet:**
  1. `id` (รหัสโปรดักID เช่น `WK-01`, `WK-02`)
  2. `productType` (ประเภท เช่น `คัดลูก`, `ชั่งโลขาย`)
  3. `name` (ชื่อสินค้า)
  4. `maturity` (ระดับความสุก เช่น `แก่จัด 85%+`, `สุกพอดีกิน`)
  5. `texture` (Texture เช่น `กรอบนอกนุ่มใน`, `เนื้อไก่ฉีก`, `นุ่มละมุน`)
  6. `stockQty` (จำนวนลูกในสต็อก)
  7. `grade` (เกรด/ไซส์ เช่น `พรีเมียม A+`, `เกรดส่งออก`)
  8. `weight` (น้ำหนักต่อลูก เช่น `3.5 - 4.0 กก.`)
  9. `image` (ลิงก์รูปภาพ)
  10. `description` (รายละเอียด / ความหวาน)
  11. `pricePerKg` (ราคาต่อกิโลกรัม)
  12. `price` (ราคาต่อลูก / ราคาประมาณการ)
  13. `isActive` (`1` = เปิดขาย (ต้องมีสต็อก $\ge 1$), `0` = ปิดขาย/หมดทันที)
  14. `createDate` (วันที่สร้าง)
  15. `createdBy` (ผู้สร้าง)
  16. `updatedAt` (วันที่อัปเดตล่าสุด)
  17. `updatedBy` (ผู้ที่อัปเดตสถานะ เช่น แอดมินที่เปิด/ปิดสต็อก)

* **คอลัมน์ที่จะนำไปแสดงใน LINE:**
  * **ชื่อ** | **น้ำหนัก** | **เกรด** | **Texture** | **รายละเอียด** | **ราคาต่อโล**

### 📦 2. แท็บ Orders (คำสั่งซื้อ / สั่งจอง)
* **รหัส Order ID:** รูปแบบ `OD123456` (รันอัตโนมัติ 6 หลักขึ้นไป)
* **คอลัมน์ที่เก็บใน Sheet:**
  1. `id` (รหัสออเดอร์ เช่น `OD000001`)
  2. `roundId` (รอบส่ง เช่น `WK-ROUND-46`)
  3. `lineUserId` (LINE User ID)
  4. `customerName` (ชื่อผู้รับ)
  5. `phone` (เบอร์โทร)
  6. `address` (ที่อยู่จัดส่ง)
  7. `productType` (ประเภทโปรดัก เช่น `คัดลูก`, `ชั่งโล`)
  8. `productId` (รหัสสินค้า)
  9. `productName` (ชื่อสินค้า)
  10. `pricePerItem` (ราคาต่อกิโลกรัม หรือราคาต่อลูก)
  11. `weightPerItem` (น้ำหนักต่อลูกจริง ที่แอดมินมาชั่งและระบุ)
  12. `quantity` (จำนวนลูก)
  13. `totalPrice` (ราคารวมคำนวณจริง: น้ำหนัก x ราคา/กก. x จำนวนลูก)
  14. `courier` (ส่งขนส่งไหน เช่น `รถห้องเย็น`, `Inter Express`)
  15. `channel` (สั่งผ่านช่องทาง เช่น `LINE OA`, `Website`, `Facebook`)
  16. `vehicleType` (รถอะไร เช่น `รถกระบะควบคุมอุณหภูมิ`)
  17. `trackingNo` (เลขพัสดุ)
  18. `orderStatus` (สถานะออเดอร์ ใช้ชุดนี้เท่านั้น: `สั่งจอง` → `รอชำระเงิน` → `ชำระเงินแล้ว/เตรียมจัดส่ง` → `กำลังจัดส่ง` → `จัดส่งสำเร็จ` หรือ `ยกเลิก` — ดู `docs/ANTIGRAVITY.md` ข้อ 2.2)
  19. `paymentStatus` (`pending` → `slip_submitted` (ลูกค้าส่งสลิป รอแอดมินตรวจ) → `confirmed` (แอดมินยืนยัน) / `refunded`)
  20. `slipUrl` (รูปสลิปโอนเงิน)
  * คอลัมน์ flow จอง (เพิ่มใหม่ — เติมเวลาเป็น ISO ตอนเข้าแต่ละขั้น):
    `weighedAt` (แอดมินชั่ง), `slipSubmittedAt` (ลูกค้าส่งสลิป), `paidAt` (แอดมินยืนยันยอด), `cancelledAt` + `cancelReason` (ยกเลิก/ปฏิเสธ), `bookingKey` (คีย์กันกดยืนยันซ้ำใน LINE — ออเดอร์ที่มี key ซ้ำห้ามสร้างใหม่)
  21. `isActive` (`1` = ใช้งาน, `0` = ยกเลิก)
  22. `createDate` (วันที่สร้าง)
  23. `createdBy` (ผู้สร้าง)
  24. `updatedAt` (วันที่อัปเดตล่าสุด)
  25. `updatedBy` (ผู้ที่อัปเดตสถานะ เช่น แอดมินที่ใส่น้ำหนักหรือปรับสถานะ)
